# sillas

# Fábrica de Sillas - Versión Extendida

Este proyecto implementa un sistema en Java para la gestión de inventario y la evaluación de retiro/permanencia de sillas en catálogo, aplicando Polimorfismo y los principios del diseño orientado a objetos.


Se implementó la Alternativa 2: Uso de una interfaz para las sillas sujetas a evaluación de retiro (Removable).
